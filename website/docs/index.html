Human Rounds documentation

Human Rounds is an AI-native medical platform for public health. AI does the repetitive work around a visit — interviewing, reading paper, summarising, filing — and the care team decides. It runs today at a public hospital in Pinamar, Argentina.

How one visit runs

  1. Before. The patient books online, on WhatsApp or at the desk, with a photo of the referral order. The AI reads the order and staff approve it. An AI interview on the patient’s own phone is a prototype.
  2. At the door. Reception registers the patient. Scanning the ID instead of typing it is a prototype.
  3. In the room. The clinician opens the day’s list of patients. A triage colour and an AI summary on that list are a prototype.
  4. After. The appointment is written into the national health record, and retried on its own if that record is down.

What it is not

It is not a diagnosis engine. Every AI output is a proposal a person approves, rejects or edits, and the existing medical record stays the source of truth. Triage rules can escalate a patient, never downgrade one.

It is not measured yet. Nothing here claims a change in waiting times, absenteeism or cost — the platform has not run long enough anywhere to have that data.

Try it or run it

The live demo is a full installation of a fictional town, rebuilt every day. To put it on your own machine, start with Install. Documentation and roadmap are on GitHub under Apache-2.0; the application code is AGPL-3.0 and is published there module by module, after privacy and security review.
