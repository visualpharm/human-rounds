# Funding and implementation roadmap

## Now

- Publish the public project site and roadmap.
- Operate a fictional-data system demo.
- Separate reviewed modules from the private prototype history.
- Document the Argentine reference architecture and system-of-record boundary.

## First funded pilot

- Select a public-health institution and a bounded operational workflow.
- Configure local identity, consent, catalogue and access rules.
- Build the authorised connector to the existing record and appointment systems.
- Rehearse end to end with synthetic data.
- Train staff and establish incident, rollback and support procedures.

## Independent evaluation

- Measure patient access and completion.
- Measure staff time, queue time and duplicate work.
- Monitor safety, alert burden and clinician overrides.
- Validate and calibrate any clinical-model output in the target population.
- Publish methods, limitations and implementation findings.

## Reusable public infrastructure

- Publish reviewed application modules.
- Publish connector interfaces and reference adapters.
- Publish operating guides and governance templates.
- Expand specialty models only with clinical partners and local validation.
- Produce country-specific interoperability packs.

Grant funding is expected to pay for implementation, integration, validation, training and support. Participating public providers in a grant-funded pilot do not need to pay a software licence fee.
